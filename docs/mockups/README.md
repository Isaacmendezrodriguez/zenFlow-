## Mockups

The folder `docs/mockups/` contains Stitch exports as `.txt` files.

These files may contain HTML and CSS generated by Stitch.

Use them as visual and animation reference only.

Do not keep the final implementation as raw HTML.

Convert the Stitch HTML/CSS into React + TypeScript + Tailwind components.

Preserve:
- Layout
- Spacing
- Visual hierarchy
- Card structure
- Sidebar style
- Topbar style
- Animations and transitions
- Hover states
- Modal behavior
- Calendar block styling

Do not blindly copy large CSS blocks.
Prefer reusable React components and Tailwind utility classes.
